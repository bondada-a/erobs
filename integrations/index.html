Beamline adaptation

The repository’s primary manual interface is the operator GUI. The direct agent and GUI chat remain experimental. Bluesky integration is not verified end to end; its guide lists the known wrapper defects.

To trace a client request in code, use Clients and integrations. Its starting functions cover direct JSON submission, MCP task construction, agent tool calls, and asynchronous Bluesky completion.

Pixi supplies ROS client and scientific/Bluesky dependencies. Running the robot stack additionally requires MoveIt, robot drivers, and any camera SDKs used by the deployment.
