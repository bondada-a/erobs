Operate EROBS

Use the operator GUI to create, preview, and execute sample-handling sequences. These guides cover task scripts, saved poses, tools, vision, and execution controls.

Start with Installation, then Run your first task for a complete mock session. For a physical installation, follow beamline configuration.

Run a sequence

  1. Create or load a task. Set Start Gripper to the attached tool, then check the target poses and step order.

  2. Preview supported sequences. Select Dry Run, press Execute, and inspect the planned motion in 3D View or RViz.

  3. Execute. Clear Dry Run and press Execute to run the sequence using the configured hardware.

  4. Check the result. Read the Log for completion, errors, and the completed-step count. For physical runs, also confirm the expected sample or tool state.

See execution controls for preview limits, pause, resume, and cancellation. Use troubleshooting to investigate a failed run.

Dry Run and mock hardware

Dry Run plans without executing task trajectories. It requires MoveIt and supports sequences containing only moveto and end_effector tasks.

Mock hardware runs the robot controller in simulation. You can preview or execute against mock hardware, as shown in the first-task walkthrough. Camera and pipettor servers are enabled separately.
