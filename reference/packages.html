Build and installation

EROBS builds with colcon; see Installation for the full procedure. The official ROS 2 workspace tutorial explains colcon, packages, and overlays.

No colcon package metadata

Importable from the source parent; not installed by colcon

The beambot CMake rules install models/spincoater_sample_seg.pt under the package share directory; the spincoater loader reads that installed path. They do not install the mcp_server/ or CMS/LIX data directories, and have no explicit install rule for the agent’s robot_operation.md prompt. Those resources are read from the source checkout.

Some package.xml dependencies are loaded by plugins or controller spawners rather than Python imports, so an unused import is not evidence that a dependency can be removed.

Optional Python features (learned vision, chat/MCP, Bluesky/EPICS) are installed separately; see optional Python features.

Repository tooling: pre-commit runs file/YAML checks, Ruff and ament linters, and some hooks rewrite files. GitHub workflows run Ruff and Super-Linter and publish Docker images; see container images.
