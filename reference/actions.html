ROS action contracts

EROBS clients submit task scripts through MTCExecution. This reference lists its fields and those of the task action servers. A ROS action carries a goal, progress feedback, and a terminal result.

Fields and comments come from the .action definitions. Use the task reference for JSON inputs and the execution guide for runtime behavior. Tutorial actions use separate interfaces.
