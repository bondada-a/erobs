Function and method reference

Use this reference when extending EROBS or investigating how a component works. Each module introduces its purpose and usage before the detailed function contracts.

Choose a subsystem below and follow its Start here links. If you already know a function name, use the symbol index. For operating the platform, start with the operator guides.

Reading an entry

Module pages explain how the code is used, identify key callables, and group methods under their owning classes. Internal callbacks and helpers follow the main methods. All entries remain searchable and directly linkable.

The role beside each signature tells you how the callable is used:

Role

Meaning

Entry point

A starting point for a workflow or for tracing its implementation. Follow the module’s usage guidance before calling it.

Extension hook

A method implemented or overridden by subclasses.

Lifecycle

Construction, initialization, cleanup, or shutdown.

Callback

Called by ROS, Qt, a timer, or another framework event.

Method / function

A regular operation used by the surrounding code.

Internal helper

Supporting implementation logic.

These labels describe usage, not a guarantee of a stable public API. An underscore alone does not determine whether a method is an extension hook.

Signatures, defaults, and annotations come from source. Parameter descriptions explain expected inputs; error notes describe validation and recovery. Uncaught exceptions propagate unless the entry describes recovery. Side-effect notes identify state changes, I/O, camera capture, and robot motion where applicable.

Referenced in source lists statically identified references. It can omit dynamic dispatch, inherited methods, GUI string lookups, ROS clients, and external callers. No listed references does not mean a function is unused.

self and cls in Python signatures refer to the current instance and class. Examples that require a running application state their context.

Source links

Source links open the snapshot of the code these entries describe.

The reference covers 806 functions and methods across 90 modules. Coverage includes first-party Python, C++, shell, and viewer functions, including private and nested helpers. It excludes tests, imported libraries, anonymous functions, inherited dependency methods, and generated dataclass methods. Scripts without named functions are covered in the command guide.
