Operator GUI

Task editing, pose storage, execution controls, chat, and robot visualization. The ROS bridge connects the Qt interface to topics, actions, and services.

Read the guide · All subsystems · Symbol index

Start here

  • open_task_form — Locate the editor selected for a task type and see how accepted edits return to the queue.

  • MTCMainWindow._execute — Follow queue validation, preview selection, and document submission from the main window.

  • ROS2Bridge.execute_task — Trace the GUI request across the ROS action boundary and back through feedback and result signals.

  • VisualizationPanel.preview_pose — See how an edited joint pose updates the viewer without submitting a robot-motion command.
