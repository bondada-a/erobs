Examples and demos

The teaching orchestrator, motion and logging stages, and a Bluesky example. Demo tasks use a separate schema; motion examples can operate the robot.

Read the guide · All subsystems · Symbol index

Start here

  • PrintStages.run — Start with the logging-only stage to understand the simplest action-to-stage boundary.

  • OrchestratorServer._execute — Follow the teaching dispatcher through its print/move task list and between-task cancellation checks.

  • MoveStages.run — Inspect the minimal CurrentState-plus-MoveTo task used for a named robot state.

  • simple_mtc_plan — See how a sequence of task files becomes ordered Bluesky set/wait operations.
