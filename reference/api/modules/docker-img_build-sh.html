Docker image build and publish

Build Docker images and push their latest tags to GHCR. These functions publish images as well as building them.

docker/img_build.sh · Source

Setup and deployment · Guide · Symbol index

How it is used

The script dispatches beambot_bsui, beambot_bsui_minimal, or all to the functions below. Each function builds without cache, tags the result, and pushes it to the configured registry; the build and publish steps are coupled.

Use the production Docker workflow for erobs-jazzy. These helpers build the separate Bluesky reference images. Check REGISTRY and registry authorization before running the script.

Functions

build_beambot_bsui()

Build the beambot_bsui image without Docker cache, tag it for the configured registry, and push it.

Entry point · Source

build_beambot_bsui()

Returns: Shell exit status; no structured result. The final success message is printed only after the push completes.

Errors: The script uses set -e, so a failed build, tag, or push normally terminates this dispatch. Docker installation, registry authorization, and valid build inputs are required.

Side effects: Reads the repository as Docker context, creates local images/tags, and pushes beambot_bsui:latest under REGISTRY (ghcr.io/bondada-a by default).

Used by: The script case dispatcher for beambot_bsui or all. Recipe: docker/bsui/Dockerfile.
