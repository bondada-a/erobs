Survey capture

Move through taught viewpoints and record camera clouds, TF, and joint states for a survey. The --dry-run option still commands motion.

scripts.survey_mapping.run_survey · Source

Perception and mapping · Guide · Symbol index

How it is used

Use this script after teaching survey viewpoints and starting the configured robot, MoveIt, and Zivid services. main() manages the recorder and node; SurveyRunner.run() visits the poses, waits for settling, and requests each capture. Joint values in the pose YAML are degrees.

The runner sends goals directly to beambot_moveto, outside the orchestrator task queue. Its --dry-run option still moves the arm: it skips camera settings, capture, and bag recording.

Start here

Callable

Purpose

main

Validate the survey options, prepare the ROS node and optional recorder, run the selected viewpoints, and clean up. Camera settings and recording are skipped in dry-run mode; movement is not.

SurveyRunner.run

Visit poses in order, wait after each successful movement, and capture unless dry_run is set. Stop on movement failure; continue to later viewpoints after a failed capture.

SurveyRunner.move_to

Send one named joint-space MoveToAction with an inline one-pose JSON registry; wait for acceptance and completion, requesting cancellation after the movement timeout.

SurveyRunner.capture

Request a capture and wait for the received-cloud count to increase. A failed Trigger response only logs a warning; a new cloud can still make the call succeed, without proving that it belongs to this request.

Functions

main()

Validate the survey options, prepare the ROS node and optional recorder, run the selected viewpoints, and clean up. Camera settings and recording are skipped in dry-run mode; movement is not.

Entry point · Source

main()

Returns: 0 for full success, 1 for invalid inputs, endpoint/recorder failure, interrupted or incomplete survey.

Errors: Argparse exits for invalid numeric constraints; pose-read failures return 1. KeyboardInterrupt is reported; unexpected runtime errors propagate after cleanup once inside the try block.

Side effects: May move hardware even with –dry-run; normal mode can change camera settings and create a bag. Destroys node, shuts down ROS and stops recorder.

stop_bag()

Finalize a running recorder by sending SIGINT to its process group, escalating to terminate and kill if waits expire.

Lifecycle · Source

stop_bag(process)

Parameter

Meaning

process

Popen returned by start_bag, or None; completed processes are ignored.

Returns: None after the process ends or is already absent.

Errors: Suppresses ProcessLookupError; escalates after 15 seconds, then five seconds. Other signal/wait errors propagate.

Side effects: Signals the recorder, waits for exit and lets it finalize its bag.

SurveyRunner

A ROS node that coordinates direct MoveTo goals and Zivid captures. Movement failure stops the sequence; a failed capture allows later viewpoints to proceed.

Inherits from: Node.

SurveyRunner.run()

Visit poses in order, wait after each successful movement, and capture unless dry_run is set. Stop on movement failure; continue to later viewpoints after a failed capture.

Method · Source

run(self, poses)

Parameter

Meaning

poses

Ordered mapping of pose name to six joint angles in degrees.

Returns: True iff all entries completed; an empty mapping succeeds.

Errors: Returns False on first movement failure or any capture failure; unexpected exceptions propagate.

Side effects: Commands arm movement, sleeps args.settle seconds, triggers captures and logs progress.

SurveyRunner.move_to()

Send one named joint-space MoveToAction with an inline one-pose JSON registry; wait for acceptance and completion, requesting cancellation after the movement timeout.

Method · Source

move_to(self, name, joints)

Parameter

Meaning

name

Pose name used as goal.target and JSON mapping key.

joints

Six arm joint angles in degrees, passed unchanged into goal.poses_json.

Returns: True only for an accepted goal whose returned result.success is true; otherwise False.

Errors: 15-second acceptance timeout/rejection, result timeout or failed/missing result are logged and return False. On movement timeout waits up to five seconds for cancellation; future exceptions propagate.

Side effects: Commands robot motion through beambot_moveto, spins ROS and may cancel the goal.

SurveyRunner.capture()

Request a capture and wait for the received-cloud count to increase. A failed Trigger response only logs a warning; a new cloud can still make the call succeed, without proving that it belongs to this request.

Method · Source

capture(self, name)

Parameter

Meaning

name

Pose label used in diagnostic messages.

Returns: True when a Trigger response arrives and any new subscribed cloud is observed; False on service-result or cloud timeout.

Errors: Uses args.capture_timeout and args.cloud_timeout seconds; timeout failures are logged. Future exceptions propagate.

Side effects: Triggers Zivid acquisition and spins ROS; does not verify the new cloud’s timestamp or source request.

SurveyRunner.apply_settings()

Set zivid_camera settings_file_path to the resolved settings file and clear settings_yaml. Missing file/service or unsuccessful response leaves the survey running.

Method · Source

apply_settings(self)

Returns: None regardless of whether settings were applied.

Errors: Missing file, 10-second service timeout, response timeout or rejected parameters produce warnings; unexpected service/future errors propagate.

Side effects: Reads file existence, creates a parameter client, requests camera parameter changes and logs results; non-atomic parameter application may partly succeed.
