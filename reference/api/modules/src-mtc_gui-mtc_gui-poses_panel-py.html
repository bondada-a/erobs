Pose browser and registry

Load, browse, and update the GUI’s shared pose registry.

mtc_gui.poses_panel · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow loads the registry through load_from_beamline_config(); load_from_file() accepts a registry path directly. pose_clicked reports a selection, pose_activated requests a Move To queue entry, and poses_loaded announces a reload. Selecting or dragging a pose does not execute it.

Use save_pose() and delete_pose() to change the registry: both read the latest file, write it atomically, then reload the panel. Comment-derived groups are display metadata and are lost on rewrite. There is no interprocess lock between GUI and other registry writers.

Method · Source

load_from_beamline_config(self, config_path: str | Path)

Parameter

Meaning

config_path

Beamline YAML path. A relative poses_file is resolved by walking upward from this path’s parent; the filesystem-root directory is not checked by the loop.

Returns: None.

Errors: Missing config, absent/false poses_file, or unresolved registry silently returns. YAML/I/O and nonmapping-config errors propagate.

PosesPanel.save_pose()

Merge one pose into the latest on-disk registry, atomically write it, then reload.

Method · Source

save_pose(self, name: str, values: list) -> bool

Parameter

Meaning

name

Pose key to insert or overwrite without duplicate-name confirmation.

values

Joint-angle list, conventionally six degrees values; no validation is performed before writing.

Returns: False if no registry path is set; True after successful write and reload.

Errors: I/O/YAML/display errors propagate. The reload filters non-six-element lists, so malformed lengths may be written but then disappear from the visible registry.

Side effects: Reads current disk state, writes the merged registry, and reloads/emits poses_loaded. YAML comments are lost; read/merge/write is not protected by a cross-process lock.

PosesPanel.delete_pose()

Remove a name from the latest on-disk registry and reload the persisted result.

Method · Source

delete_pose(self, name: str) -> bool

Parameter

Meaning

name

Pose key to remove; absent keys are tolerated.

Returns: False if no registry path is set; otherwise True after write/reload, even when the name was absent.

Errors: I/O/YAML/display errors propagate.

Side effects: Rewrites the registry and reloads/emits poses_loaded; comments are lost even when the requested key did not exist.
