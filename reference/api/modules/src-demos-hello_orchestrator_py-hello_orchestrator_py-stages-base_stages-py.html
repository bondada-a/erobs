Demo motion-stage base

Build and execute MTC tasks for the teaching motion demo.

hello_orchestrator_py.stages.base_stages · Source

Examples and demos · Guide · Symbol index

How it is used

Derived demo stages use create_task_template() to start an MTC task, make_pipeline_planner() to create an OMPL planner, and load_plan_execute() to plan and execute the first solution. The planning group is ur_arm, with velocity and acceleration scaling set to 0.2.

Importing this module initializes rclcpp and a shared MTC node. It therefore needs a ROS/MoveIt environment even before a stage instance is constructed.

BaseStages

Provide shared task construction and plan/execute helpers for motion demos. Operations use the module-global MTC node and report a boolean outcome.

BaseStages.create_task_template()

Create an MTC Task, assign its name, load the robot model using the shared MTC node and add CurrentState as its first stage.

Method · Source

create_task_template(self, task_name: str) -> core.Task

Parameter

Meaning

task_name

Task name used by MTC and later diagnostics.

Returns: core.Task with its model loaded and one CurrentState stage.

Errors: Robot-model/MTC construction errors propagate to the enclosing action callback.

Side effects: Loads robot model/parameters and allocates MTC task state; no planning/execution yet.

BaseStages.make_pipeline_planner()

Create an OMPL PipelinePlanner with velocity and acceleration scaling factors both set to 0.2.

Method · Source

make_pipeline_planner(self)

Returns: Configured core.PipelinePlanner.

Errors: Planner construction/configuration errors propagate.

Side effects: Initializes planning resources; no robot command.

BaseStages.load_plan_execute()

Initialize and plan for at most one solution, require a nonempty solutions list and execute the first solution, checking MoveItErrorCodes.SUCCESS.

Method · Source

load_plan_execute(self, task: core.Task) -> bool

Parameter

Meaning

task

Configured MTC core.Task to plan and execute.

Returns: True only for successful planning plus successful trajectory execution; otherwise False.

Errors: Catches all Exceptions and logs failure; false planning/no-solution/error-code cases also log and return False.

Side effects: Computes a motion plan and may execute robot trajectories; logs progress/outcome.

BaseStages.__init__()

Retain the caller node/logger, share the module-global MTC node and set planning group ur_arm.

Lifecycle · Source

__init__(self, node)

Parameter

Meaning

node

ROS node providing get_logger(); distinct from the global rclcpp MTC node.

Errors: Missing get_logger or initialization errors propagate.

Side effects: Sets stage state; the global MTC node was already created at module import.
