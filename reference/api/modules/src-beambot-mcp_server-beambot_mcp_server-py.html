MCP robot tools

Provide MCP tools for robot state, camera observations, pose editing, image analysis, and task construction. Most tools return JSON text; ping() returns plain text.

Import requires ROS, OpenCV, and MCP and probes display settings. Beamline configuration is cached after its first successful load; pose files are reread for each registry operation. Image-saving tools may not report a failed cv2.imwrite.

src.beambot.mcp_server.beambot_mcp_server · Source

Clients and integrations · Guide · Symbol index

How it is used

MCP clients call the decorated tool functions for robot state, saved poses, camera observations, detection, and task construction. main() runs the stdio server. ROS2Bridge creates its node and background executor on first node access; the bridge callbacks maintain the caches used by tools.

Choose the tool by its effect: capture_image() requests a Zivid capture or reads a ZED frame; detection tools analyse cached data; vision_target() and pickup_tip() return task JSON for a separate submission step. stop_robot() requests orchestrator cancellation, not a hardware emergency stop. Grid task generation shares expand_grid_target() with the orchestrator, so both paths apply the same grid rules.

Example

For a configured tip_rack target, an MCP client can call vision_target with:

{"target_name": "tip_rack", "row": 0, "col": 0}

The response contains a task_json string plus target metadata, or an error. Generating this document reads configuration and saved poses; it does not submit the task. Grid rows and columns are zero-based.

capture_image()

For Zivid call the existing /capture Trigger and wait for image plus optional cloud; for ZED use the latest stream frame or wait briefly for its first frame. Save the RGB cache as a BGR-encoded image.

Entry point · Source

@mcp.tool()
async capture_image(

    mode: str = '3d',
    save_path: str = DEFAULT_IMAGE_PATH,
    timeout: float = 30.0,
) -> str

Parameter

Meaning

camera

Exact zivid or zed camera selector.

mode

Only exact 3d sets need_cloud=True for Zivid; any other string behaves as image-only waiting. It does not select a distinct 2D acquisition service. ZED ignores it.

save_path

Image destination; parent directories are created and existing file may be overwritten.

timeout

Side effects: May initialize ROS, trigger Zivid, wait for streaming data, create directories and overwrite an image.

detect_objects()

Detect objects in the cached image using HSV, ArUco, or YOLO. YOLO receives an RGB-to-BGR conversion. Optionally add point-cloud coordinates, transform them to base_link, and save detected objects. This function does not capture images or execute tasks.

Depth lookup requires image-aligned, little-endian XYZ float32 records. It searches expanding square pixel rings and returns the first valid point without averaging.

Entry point · Source

    method: str = 'hsv_color',
    camera: str = 'zivid',
    hue_low: int = 100,
    hue_high: int = 130,
    sat_min: int = 80,
    val_min: int = 80,
    min_area: int = 200,
    marker_ids: str = '',
    yolo_model: str = 'yolov8n.pt',
    yolo_confidence: float = 0.25,
    yolo_classes: str = '',
    transform_to_base: bool = True,
    save_path: str = DEFAULT_ANNOTATED_PATH,
) -> str

Parameter

Meaning

method

Exact hsv_color, marker or yolo.

camera

Cached data source: zivid or zed.

hue_low

HSV lower hue bound on OpenCV scale; used only for hsv_color.

hue_high

HSV upper hue bound; one nonwrapping interval for hsv_color.

sat_min

HSV minimum saturation (0–255).

val_min

HSV minimum value/brightness (0–255).

min_area

Minimum external-contour area in square pixels for HSV.

marker_ids

Comma-separated integer IDs for marker mode; empty means all.

yolo_model

Generic YOLO weight/model path passed to the shared detector.

yolo_confidence

Minimum YOLO confidence fraction, conventionally 0–1, without local validation.

yolo_classes

Comma-separated numeric IDs if every token is digits, otherwise case-insensitive class names; empty keeps all.

Request base_link coordinates for valid depth; failure leaves base_xyz null.

save_path

Annotated image destination; parent directories are created only for nonempty detections.

Errors: Unknown method/camera or missing image returns error JSON. Bad ID text, detector/model, depth, filesystem and OpenCV exceptions propagate; image-write false results are ignored.

Side effects: Reads ROS caches and TF, may load generic YOLO weights (its library may resolve/download named weights), and writes annotation; does not trigger acquisition or move hardware.

_detect_hsv_color(

Parameter

Meaning

rgb_image

H×W×3 RGB image array accepted by cv2.cvtColor.

hue_low

Inclusive HSV hue lower threshold, OpenCV hue scale approximately 0–179.

hue_high

Inclusive hue upper threshold; a single contiguous interval is used, without wraparound.

sat_min

Inclusive saturation lower threshold, 0–255 scale.

val_min

Inclusive brightness/value lower threshold, 0–255 scale.

Minimum cv2 contour area in square pixels; equal area passes.
