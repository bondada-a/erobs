Survey point-cloud merger

Merge recorded survey clouds into a binary PLY file using TF or URDF transforms, range filtering, and voxel averaging. Processing is offline but requires ROS Python dependencies.

scripts.survey_mapping.merge_survey_bag · Source

Perception and mapping · Guide · Symbol index

How it is used

Use main() to turn a recorded survey bag into a PLY point cloud for the Isaac Sim workflow. Run the script after sourcing ROS and the workspace; it reads files and needs no running ROS graph. The helpers below handle cloud extraction, coordinate transforms, and voxel averaging.

Recorded TF is the default alignment source. Supplying --urdf replaces TF lookup with forward kinematics using the latest preceding joint-state message. Neither mode refines the camera calibration or performs ICP alignment.

Start here

Callable

Purpose

main

Merge the bag’s clouds into one PLY file. Range-filter points in the incoming camera frame, transform them using recorded TF or joint states with the URDF, then voxel-average them. If any included cloud lacks color, omit color from the final map.

UrdfFkSolver.lookup

Return the transform from source to target using the URDF and supplied joint positions. Both frames must exist; disconnected URDF roots are not explicitly rejected.

voxel_downsample

Group floor(xyz/leaf) cells and average coordinates and optional RGB per cell. Color means are clipped and truncated to uint8.

write_ply

Serialize point coordinates as little-endian float32 vertices with optional unsigned-byte red/green/blue fields.

Example

From the repository root, merge an existing survey bag:

python3 scripts/survey_mapping/merge_survey_bag.py \
  --bag survey_session --out survey_map.ply --voxel 0.005

The voxel size is 5 mm. Use a new output filename to keep an earlier map; an existing PLY file is overwritten.

Functions

main()

Merge the bag’s clouds into one PLY file. Range-filter points in the incoming camera frame, transform them using recorded TF or joint states with the URDF, then voxel-average them. If any included cloud lacks color, omit color from the final map.

Entry point · Source

main()

Returns: Integer exit code: 0 after PLY/self-check, 1 for missing inputs or no mergeable clouds.

Errors: Argparse exits for missing –bag or negative range/voxel; known URDF load errors return 1; transform failures skip clouds with warnings. Bag deserialization, extraction and PLY write errors can propagate.

Side effects: Reads bag/optional URDF, prints progress/warnings and overwrites –out (default survey_map.ply); no robot movement.

voxel_downsample()

Group floor(xyz/leaf) cells and average coordinates and optional RGB per cell. Color means are clipped and truncated to uint8.

Function · Source

voxel_downsample(xyz, rgb, leaf)

Parameter

Meaning

xyz

N×3 coordinate array, normally metres.

rgb

Matching N×3 colors, or None to omit color.

leaf

Voxel edge in the same units as xyz; zero or negative disables sampling.

Returns: (sampled_xyz, sampled_rgb); returns original objects for leaf <= 0 or empty input, otherwise one centroid per lexicographically ordered occupied cell.

Errors: Shape, nonfinite coordinate and incompatible dtype errors are not caught.

Side effects: Allocates aggregate arrays; does not mutate supplied arrays.

Example

xyz, rgb = voxel_downsample(np.array([[0., 0, 0], [0.4, 0, 0], [1.1, 0, 0]]), None, 1.0)
assert np.allclose(xyz, [[0.2, 0, 0], [1.1, 0, 0]])
assert rgb is None

xyz_rpy_matrix()

Build a homogeneous transform from fixed-axis XYZ Euler rotation and translation.

Function · Source

xyz_rpy_matrix(xyz, rpy)

Parameter

Meaning

xyz

Three translation components, conventionally metres.

rpy

Roll, pitch, yaw in radians, applied with tf_transformations axes=”sxyz”.

Returns: NumPy 4×4 homogeneous matrix with xyz in its translation column.

Errors: Invalid vector shape or numeric values are not caught.

Side effects: Allocates a matrix only.

UrdfFkSolver

Compute frame transforms from an expanded URDF and a joint-position mapping. This is the merger’s optional alternative to recorded TF; it does not model mimic joints.

UrdfFkSolver.lookup()

Return the transform from source to target using the URDF and supplied joint positions. Both frames must exist; disconnected URDF roots are not explicitly rejected.

Method · Source

lookup(self, target, source, angles)

Parameter

Meaning

target

Destination link frame.

source

Source link frame.

angles

Mapping of movable joint positions, radians for rotation and metres for translation.

Returns: 4×4 transform taking points from source to target.

Errors: ValueError for absent frames, cycles or missing positions; inversion errors propagate. No explicit check ensures target and source share one root.

Side effects: Computes transforms without publishing TF.

UrdfFkSolver.__init__()

Parse each URDF joint into a child-link-to-joint table containing name, type, parent, origin transform and axis. Missing origin defaults to zero and missing axis to +X; mimic behavior is not modeled.
