Robot and trajectory viewer

Display the robot, task previews, and configured obstacles in an embedded 3D viewer.

mtc_gui.visualization_panel · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow creates VisualizationPanel and connects joint, gripper, and trajectory signals. The panel starts a loopback HTTP server for viewer assets and robot meshes, then waits for the embedded WebEngine page before loading the model. Its controls and previews affect the display only.

Use preview_pose() and end_preview() around a task editor’s goal preview; play_trajectory() animates an orchestrator preview. Pose lists use degrees, while trajectory waypoint positions use radians. Python uses the configured arm-joint order, but the JavaScript viewer still expects six fixed UR joint names. closeEvent() stops the panel’s timer and mesh server.

VisualizationPanel.play_trajectory()

Convert trajectory waypoints into arm poses and animate them in the viewer.

Callback · Source

play_trajectory(self, _unused_names, waypoints)

Parameter

Meaning

_unused_names

Ignored compatibility signal argument; names come from each waypoint.

waypoints

Sequence of (joint_names, positions_in_radians, cumulative_seconds). Named positions may include arm or gripper joints; complete arm samples are converted to degrees rounded to three decimals.

Returns: None.

Errors: Returns before readiness or for no points; malformed names/positions/times raise. Does not validate chronological order or that all points have six arm joints.

Side effects: Seeds from the first complete arm sample or six zeros, holds the last arm state across partial/gripper-only points, stores the full track, duration from its last point, and monotonic start; shows preview controls and starts the timer. It does not set _preview_hold, so live updates can interleave with playback.

VisualizationPanel._reload_scene()

Load supported obstacle shapes from the configured scene into the viewer.

Callback · Source

_reload_scene(self)

Returns: None.

Errors: Missing path and YAML read/parse exceptions update status and return. Per-obstacle KeyError/TypeError/ValueError entries are skipped; unsupported types are skipped. A nonmapping YAML root, malformed obstacle object raising AttributeError, short box size raising IndexError, or JavaScript-call error can still propagate despite the docstring’s broader promise.

Side effects: Reads YAML and emits window.setSceneObstacles([{name,type,pos:[x,y,z],rot:[roll,pitch,yaw],dims:{size|height,radius}}]); positions and dimensions are interpreted as metres and rotations as radians by viewer.html, with no per-obstacle frame transform in this Python path. JavaScript replaces the existing displayed obstacle list. Updates obstacle/skipped count status; makes no planning-scene service call.
