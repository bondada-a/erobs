Task queue display

Show editable task rows, selection, and execution progress.

mtc_gui.step_list_panel · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow owns the task document and calls StepListPanel.refresh() to render it. The panel emits row selections, edit requests, pose drops, and reorder requests; the window applies those changes to the document. All widget updates belong on the GUI thread.

During a run, the window calls start_execution(), forwards feedback to update_step(), and completes the display with finish_execution(). Feedback steps are one-based within the submitted sequence; start_index maps them back to the full queue. Pausing changes the status indicator but does not stop elapsed-time counters.

StepListPanel.start_execution()

Prepare the queue display for a run beginning at the specified row.

Method · Source

start_execution(self, total_steps: int, start_index: int=0)

Parameter

Meaning

total_steps

Full queue-step count used by the toolbar.

start_index

Zero-based first row to execute; callers provide a valid nonnegative index.

Returns: None.

Errors: No bounds validation beyond the first-next check; negative values follow Python slicing/indexing behavior and can fail on an empty list.

Side effects: Disables the panel’s editing flag, resets suffix rows to PENDING, clears/sets next badges, shows toolbar, and starts the elapsed timer. The list’s drag flags are changed separately by set_editing_enabled.

Method · Source

update_step(self, current_step: int, progress: float, action_name: str)

Parameter

Meaning

current_step

One-based step number within the submitted execution suffix.

progress

Accepted feedback percentage but not used; toolbar percentage is recomputed from the full-queue row index.

Task-type label displayed by the toolbar.

Returns: None.

Errors: Ignores nonpositive or out-of-range step indices; other type/Qt errors propagate.

Side effects: Updates row states/badges/current index, toolbar step/percentage, and scrolls to the active item. A row timer restarts only when that row first becomes RUNNING.

StepListPanel.finish_execution()

Stop timing and mark the executed queue segment from the reported result.

Method · Source

finish_execution(self, status: str, completed_steps: int)

Parameter

Meaning

status

“success” marks every suffix row DONE; any other value marks the first uncompleted row FAILED and later rows PENDING.

completed_steps

Completed count relative to _execution_start_index.

Returns: None.

Errors: No completion-count bounds validation; Qt errors propagate.

Side effects: Sets execution inactive/editing flag true, stops timer, clears all next badges, preserves skipped prefix states, marks suffix states, and hides toolbar. Drag/drop flags are not changed here.
