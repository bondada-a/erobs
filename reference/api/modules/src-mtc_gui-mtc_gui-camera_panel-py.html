Camera display

Display camera images and marker detections in the operator GUI.

mtc_gui.camera_panel · Source

Operator GUI · Guide · Symbol index

How it is used

Create CameraPanel with the window’s ROS2Bridge. The constructor connects image and detection signals to GUI-thread callbacks and routes its Capture and Detect Markers buttons to the bridge’s services. Those buttons request camera work; the panel does not perform detection itself.

on_image() displays BGR images. on_detection() draws marker outlines on a copy of the latest image and lists detected positions in metres. These are separate incoming signals, so the overlay uses the panel’s current image rather than matching a capture identifier.

CameraPanel

A Qt widget that owns the camera viewport and detection text. It receives data from ROS2Bridge and forwards button requests to that bridge.

Inherits from: QWidget.

CameraPanel.on_detection()

Cache marker results, draw four-corner outlines and ID labels on the latest image, and list marker positions.

Callback · Source

on_detection(self, markers)

Parameter

Meaning

markers

List of marker objects exposing id, corners_in_pixel_coordinates (points with x/y), and pose.position.x/y/z in metres.

Returns: None.

Errors: Empty lists show a no-markers warning and return. Non-four-corner markers skip only the overlay; malformed attributes or drawing errors propagate.

Side effects: Updates current_detections, status, and detection text; overlays a copy of current_image without modifying the stored original.
