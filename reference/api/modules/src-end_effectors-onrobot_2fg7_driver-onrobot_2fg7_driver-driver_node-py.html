2FG7 ROS driver

Expose the 2FG7 gripper through a ROS action and joint-state publisher, with hardware and mock modes.

onrobot_2fg7_driver.driver_node · Source

Tools and end effectors · Guide · Symbol index

How it is used

This node connects the ROS GripperCommand interface to the 2FG7 Modbus client, or uses mock state when configured. main() owns the ROS executor; ROS invokes the action and timer callbacks. Constructing OnRobot2FG7DriverNode can open the hardware connection.

ROS positions represent one finger’s travel in metres, while the hardware uses the full external width in millimetres. Check both the action status and reached_goal in the result: a succeeded action can report reached_goal=False. Accepted cancellation does not send a hardware stop.

OnRobot2FG7DriverNode._execute_gripper_command

Handle a GripperCommand goal by converting finger position to external width, sending the grip command, and polling hardware status. Use a positive requested effort or the configured default force; compare final width against a strict 5 mm tolerance. Poll every 0.1 seconds, allowing at least 0.3 seconds before accepting an idle reading and roughly five seconds of nominal polling overall.

joint_pos_to_width_mm()

Compute 1 + 2000×joint position and clamp external width to the physical 1–73 mm interval.

Function · Source

joint_pos_to_width_mm(joint_pos_m: float) -> float

Parameter

Meaning

joint_pos_m

One-sided finger prismatic travel in metres.

Returns: Clamped float external width in millimetres; 0.036 m reaches 73 mm.

Errors: Invalid numeric types propagate; no explicit NaN/infinity validation.

Side effects: Pure arithmetic.

Example

assert joint_pos_to_width_mm(0) == 1.0
assert joint_pos_to_width_mm(0.0365) == 73.0

width_mm_to_joint_pos()

Subtract the 1 mm minimum external width, halve the remainder and convert millimetres to metres, clamping only below zero.

Function · Source

width_mm_to_joint_pos(width_mm: float) -> float

Parameter

Meaning

width_mm

Full external opening in millimetres.

Returns: Nonnegative one-finger travel in metres; no upper bound is applied.

Errors: Invalid numeric inputs propagate; no finite-value validation.

Side effects: Pure arithmetic.

Example

OnRobot2FG7DriverNode._execute_gripper_command()

Handle a GripperCommand goal by converting finger position to external width, sending the grip command, and polling hardware status. Use a positive requested effort or the configured default force; compare final width against a strict 5 mm tolerance. Poll every 0.1 seconds, allowing at least 0.3 seconds before accepting an idle reading and roughly five seconds of nominal polling overall.

Callback · Source

_execute_gripper_command(self, goal_handle)

Parameter

Meaning

goal_handle

Accepted GripperCommand handle. request.command.position is one-sided metres; max_effort >0 becomes integer newtons, otherwise default_force is used.

Returns: GripperCommand.Result with position in metres, zero effort, and reached_goal reflecting final width tolerance. Mock mode sleeps 0.5 seconds and reports success/reached_goal=True using the original position. Real missing connection/write failure aborts; cancellation returns reached_goal=False; final mismatch or unreadable status still calls succeed().

Errors: Read/write exceptions propagate. Nominal timeout excludes serial blocking duration. Cancellation is checked only in real polling and issues no hardware stop; the driver has no explicit lock around cached width or Modbus access.

Side effects: Commands physical fingers, reads status, updates width cache, publishes action feedback and sets terminal action status.

OnRobot2FG7DriverNode._connect_gripper()

Create a client per attempt, require both connection and status read, cache initial width on success and leave gripper=None after exhausted attempts.

Internal helper · Source

_connect_gripper(self, max_retries=10, retry_delay=2.0)

Parameter

Meaning

max_retries

Number of connection attempts; zero makes no attempt.

retry_delay

Seconds slept between unsuccessful attempts, not after the last one.

Returns: None whether connected or exhausted; inspect self.gripper for outcome.

Errors: Expected failed connect/status responses log; successful connection with no status is disconnected. Transport exceptions propagate and are not retried by this method.

Side effects: Opens/reads/closes serial connections, sleeps and logs; updates hardware handle and cached width.
