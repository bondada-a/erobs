Example topic listener

Minimal ROS 2 chatter subscriber used by the launch-script examples; importing defines the node, while the entry point initializes and spins ROS.

scripts.pdf-launch-scripts.simple_listener · Source

Examples and demos · Guide · Symbol index

How it is used

Use this small example to follow a ROS subscription from node creation to message handling. main() owns ROS startup and shutdown; ROS calls MinimalSubscriber.listener_callback() for each chatter message. This listener is separate from the EROBS task system.

Start here

Callable

Purpose

main

Initialize ROS, construct the listener, and spin until execution returns, then destroy the node and shut down ROS.

MinimalSubscriber.listener_callback

Log the payload of each chatter message in an “I heard” line.

main()

Initialize ROS, construct the listener, and spin until execution returns, then destroy the node and shut down ROS.

Entry point · Source

main(args=None)

Parameter

Meaning

args

Optional ROS initialization argument list; None uses process arguments.

Returns: None after spin returns.

Errors: No try/finally: an exception or interrupt during spin can bypass explicit cleanup.

Side effects: Starts ROS and blocks processing subscriptions; normal completion destroys the node and ROS context.

MinimalSubscriber

A ROS node that subscribes to String messages on chatter and logs their contents.

Inherits from: Node.

Callback · Source

Parameter

Meaning

msg

std_msgs.msg.String received on chatter; its data field is logged.

Returns: None.

Errors: Malformed message/logger errors propagate.

Side effects: Writes an INFO ROS log.
