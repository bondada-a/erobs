Traced task runner

Run a traced task and clean up the launched processes. Normal execution submits a task to the orchestrator and can move hardware.

src/beambot/scripts/perf_trace_run.sh · Source

Task execution · Guide · Symbol index

How it is used

This command launches Beambot with tracing enabled, waits for the execution action, submits a task file, and reports the new trace directory. Normal execution can move hardware. Use the command guide for the surrounding startup workflow.

The only named shell function is cleanup(). It runs on exit and after task completion to shut down the launch process and allow tracing to finalize; it is not a separate user command.

Start here

Callable

Purpose

cleanup

Request a clean launch shutdown, wait up to thirty half-second polling intervals, and force termination if the stored process is still alive.

Functions

cleanup()

Request a clean launch shutdown, wait up to thirty half-second polling intervals, and force termination if the stored process is still alive.

Lifecycle · Source

cleanup()

Returns: Shell status; no structured result.

Errors: Process-signal errors are redirected and tolerated with || true. The wait checks the stored launch PID, not every descendant.

Side effects: Sends SIGINT and potentially SIGKILL to LAUNCH_PID; allows time for launch and tracing cleanup.

Used by: EXIT trap and the explicit post-task cleanup call. The script removes the trap after explicit cleanup.
