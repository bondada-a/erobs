Shared vision engine

Shared vision engine for camera acquisition, capture-time TF, multi-view scans, approach geometry, and configured collision objects. It also inherits MTC helpers from BaseStages. Some functions capture or move hardware; others only compute geometry. Its scan cache belongs to this engine instance and is not shared with other servers.

beambot.vision.vision_engine · Source

Perception and mapping · Guide · Symbol index

How it is used

Vision servers and sample stages own a VisionEngine to connect a camera backend with TF and motion support. Start with detect_and_transform_tag() or detect_and_transform_sample_roi() for base-frame results; compute_approach_pose() converts a detected pose into a tool approach.

scan_all_tags() and detect_tag_multiposition() also move the arm through scan poses. The tag cache belongs to the engine instance. Marker-linked collision objects are experimental and only added when configured; reset_tf() replaces transform resources after robot-model changes.

Related data types:

  • ObjectInfo: Configured collision primitive dimensions and marker-local placement offset.

  • GripperDetection: Resolved tool-tip frame and the configured vertical offset used for approach geometry.

VisionEngine.compute_approach_pose()

Choose an IK frame, rotate marker-local offsets into base_link, add a vertical offset, and construct a tool-down approach orientation.

Method · Source

compute_approach_pose(
    self,
    target: PoseStamped,
    z_offset_override: float = 0.0,
    marker_offset_x: float = 0.0,
    marker_offset_y: float = 0.0,
    marker_offset_z: float = 0.0,
    ik_frame_override: str = '',
) -> tuple[PoseStamped, str]

Parameter

Meaning

target

PoseStamped assumed to already be in base_link. Its header is reused.

z_offset_override

Metres along base Z; zero selects the configured tool offset rather than requesting zero clearance.

marker_offset_x

Metres along marker-local X.

marker_offset_y

Metres along marker-local Y.

marker_offset_z

Metres along marker-local Z, before the separate base-Z offset.

ik_frame_override

Explicit IK frame. Otherwise a configured non-flange frame is used, then configured TF tip-frame detection.

Returns: (new approach PoseStamped, selected IK frame string). Orientation uses roll=180°, pitch=0°, and yaw derived after rotating marker orientation by 180° about Z.

Errors: No explicit input-frame, reachability, collision, or finite-value validation. Configuration, TF, and quaternion calculation errors can propagate.

Side effects: Reads configuration and may wait for tool-frame TF; logs geometry. Does not plan or execute motion.

VisionEngine.scan_all_tags()

Visit scan poses, capture all visible markers repeatedly, and cache averages for markers seen at least twice.

Method · Source

scan_all_tags(
    self,
    scan_positions: list[list[float]],
    scans_per_position: int = 3,
    timeout: float = 10.0,
    settle_time: float = 0.3,
) -> int

Parameter

Meaning

scan_positions

Sequence of six-joint poses in radians; _move_to_joint_pose checks each length.

scans_per_position

Number of captures per reached pose; nonpositive values produce no captures at that pose.

timeout

Seconds passed to each individual backend capture, not a deadline for the whole scan.

settle_time

Positive seconds to sleep after each successful move.

Returns: Number of marker IDs with averaged poses stored in _tag_pose_cache. Markers with only one usable detection are excluded.

Errors: Failed scan moves and unavailable transforms are skipped. Camera/averaging exceptions can propagate; no outer recovery or return-to-start move is provided.

Side effects: Clears the existing cache before scanning, executes PTP arm moves, captures images, waits for settling, and stores averaged base-frame poses. Does not publish the cache to another process.

VisionEngine.detect_tag_multiposition()

Visit supplied scan poses and average at least two successful detections of one marker.

Method · Source

detect_tag_multiposition(
    self,
    tag_id: int,
    scan_positions: list[list[float]],
    timeout: float = 45.0,
    settle_time: float = 0.3,
) -> PoseStamped | None

Parameter

Meaning

tag_id

Marker ID to detect.

scan_positions

Joint-pose sequence in radians.

timeout

Seconds per detection attempt; each position can also incur engine retries and retry delay.

settle_time

Positive settling sleep after reaching each scan pose, in seconds.

Returns: Averaged base_link PoseStamped or None if fewer than two detections succeed. This method does not insert the average into _tag_pose_cache.
