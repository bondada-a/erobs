Pose editing dialogs

Edit joint poses and choose where to save them.

mtc_gui.pose_dialogs · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow opens PosesManagerDialog with its existing PosesPanel to manage the shared registry. Each accepted add, edit, import, or deletion is saved immediately through the panel; closing the manager does not undo those changes. Joint values use degrees.

PoseEditorDialog returns six edited angles after acceptance. SavePoseDialog returns a pose name, values, and a choice of registry or task-only storage. The caller applies that choice; the save dialog does not write the file itself.
