Demo task orchestrator

Dispatch demo print and named-state motion tasks in sequence.

src.demos.hello_orchestrator_py.scripts.orchestrator_server · Source

Examples and demos · Guide · Symbol index

How it is used

The teaching orchestrator receives one demo JSON sequence, dispatches print or named-state move actions, and publishes progress between steps. Follow _execute() for sequencing and _dispatch_print() / _dispatch_move() for the child requests. ROS invokes the admission, cancellation, and execution callbacks.

Cancellation is checked between tasks. A child timeout fails the sequence without canceling that child. The implementation retains the default callback group and executor configuration; it is not the production EROBS orchestrator.

OrchestratorServer._execute()

Run demo print and move tasks in order, publish step feedback, and count completed tasks. Check cancellation between tasks; abort for a missing or unknown type or a failed child action.

Method · Source

_execute(self, goal_handle: ServerGoalHandle) -> OrchestratorTask.Result

Parameter

Meaning

goal_handle

Handle carrying request.task_json with tasks list of mappings.

Returns: Result {success,completed_steps,error_message}; empty task list succeeds; cancellation/failure preserves completed count.

Errors: JSONDecodeError/missing tasks KeyError become aborted invalid-JSON result. Wrong JSON/task types, dispatch exceptions and callback failures are not caught. Cancellation after the final task can be missed because no final check runs.

Side effects: Executes child print/move actions, publishes feedback, logs and sets parent action terminal state.

OrchestratorServer._call_action()

Wait five seconds for a child server, up to ten seconds for acceptance and timeout_sec for completion; expose the child payload success.

Internal helper · Source

_call_action(self, client, goal, timeout_sec: float=60.0) -> bool

Parameter

Meaning

client

ROS ActionClient for PrintMessage or MoveToNamedState.

goal

Matching generated child goal.

timeout_sec

Seconds to wait for child result, additional to discovery/acceptance waits.

Returns: False for unavailable server, acceptance timeout/rejection or result timeout; otherwise child result.success.

Errors: Future/malformed-result errors propagate. A timed-out or late-accepted goal is not canceled, so child work may continue after False.

Side effects: Sends child action, synchronously spins ROS within the parent callback and logs failures.
