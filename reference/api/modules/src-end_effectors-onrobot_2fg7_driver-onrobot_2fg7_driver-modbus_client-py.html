2FG7 Modbus client

Low-level 2FG7 Modbus RTU client over the UR tool serial bridge. Writes width/force/speed/mode registers at 0x0000 and reads eight status registers at 0x0100. Dataclass GripperStatus holds decoded widths, busy flag, raw status and registers; no auto-connect at construction.

onrobot_2fg7_driver.modbus_client · Source

Tools and end effectors · Guide · Symbol index

How it is used

OnRobot2FG7Client is the serial transport used by the ROS driver. Construction configures the client; connect() opens the connection. Read status through read_status(), send grip commands through the mode-specific methods, and call disconnect() when finished.

Widths are in millimetres, force in newtons, and speed in percent. A successful command means the register write succeeded, not that the gripper reached its requested width. Callers must inspect status to determine completion; is_busy() alone cannot distinguish an idle gripper from a failed status read.

OnRobot2FG7Client.grip_external()

Send a width/force/speed command in external (1) mode through the shared register encoder.

Method · Source

grip_external(self, width_mm: float, force_n: int=40, speed_pct: int=100) -> bool

Parameter

Meaning

width_mm

Target gripper width in millimetres.

force_n

Requested newtons, clamped to 0–140 by _write_command.

speed_pct

Requested speed percent, clamped to 1–100.

Returns: Boolean command-write acceptance; does not wait for motion or grip confirmation.

Errors: Returns False for Modbus error response; conversion/transport exceptions propagate.

OnRobot2FG7Client.is_busy()

Read the gripper status and return its busy flag. A failed status read also returns False, so this method alone cannot confirm that the gripper is idle.

Method · Source

is_busy(self) -> bool

Returns: Boolean busy flag; False is ambiguous between idle and failed read.

Errors: Transport/decode errors propagate despite response errors mapping to False.

Side effects: Performs a Modbus status read.

Internal callbacks and helpers

OnRobot2FG7Client._write_command()

Encode width to rounded tenths of a millimetre and write four command registers, clamping force, speed and mode.

Internal helper · Source

_write_command(self, width_mm: float, force_n: int, speed_pct: int, mode: int) -> bool

Parameter

Meaning

width_mm

Requested width in millimetres; rounded ×10 and clamped only at zero, with no upper register/physical-width bound here.

force_n

Force in newtons, int-converted and clamped to 0–140.

speed_pct

Speed percentage, int-converted and clamped to 1–100.

mode

Mode integer clamped to 1–2: external/internal grip.

Returns: True for a nonerror Modbus write response, False for result.isError(); not a motion-completion indication.

Errors: Error responses log when a logger exists; transport, invalid numeric and register-range exceptions propagate.

Side effects: Writes device registers and can initiate gripper motion.
