GUI appearance

Apply the shared colors, fonts, icons, and widget styles.

mtc_gui.theme · Source

Operator GUI · Guide · Symbol index

How it is used

Call apply() on the QApplication during startup. toggle_dark_mode() applies the same dark theme or restores the style’s standard palette and clears the stylesheet; it leaves the existing font and Fusion style in place. The main window’s appearance menu calls this helper.

Widgets use the module’s constants and icon() helper for consistent appearance. Call restyle() after changing a dynamic property, such as the plan-cache badge’s status. Use these helpers on the GUI thread. Missing icon support falls back to an empty icon, and unavailable Inter fonts fall back to Sans Serif.

toggle_dark_mode()

Apply the shared dark theme when enabled, or restore the style’s standard palette and clear the stylesheet when disabled.

Function · Source

toggle_dark_mode(app: QApplication, enabled: bool) -> None

Parameter

Meaning

app

QApplication to update.

enabled

Truthy selects the shared theme; false selects palette/stylesheet reset.

Returns: None.

Errors: Qt/theme exceptions propagate.

Side effects: Updates application appearance. The disabled branch does not undo the font or Fusion style previously set by theme.apply.

Parameter

Meaning

name

qtawesome icon identifier, for example “mdi6.play”.

color

Icon color passed to qtawesome, defaulting to the theme’s primary text color.
