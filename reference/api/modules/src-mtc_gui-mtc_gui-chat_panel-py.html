Chat interface

Present messages, tool calls, execution outcomes, and Plan/Run controls.

mtc_gui.chat_panel · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow connects ChatPanel to AgentBridge. The panel emits message_submitted and mode_change_requested; bridge signals feed its message and status methods. The panel itself neither opens an agent connection nor submits robot goals.

Update this widget on the GUI thread. Messages are rendered as plain text, tool details expand on demand, and set_thinking() controls both the animation and input availability. Mode radios remain disabled until the bridge acknowledges a change through the main window.
