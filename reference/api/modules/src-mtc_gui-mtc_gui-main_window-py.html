Operator window

Coordinate task editing, saved runs, pose management, chat, and execution controls.

mtc_gui.main_window · Source

Operator GUI · Guide · Symbol index

How it is used

main() creates MTCMainWindow with the application’s ROS2Bridge. The window owns the active task document, builds the panels, connects their signals, loads beamline poses, and starts its AgentBridge. Registry poses remain in PosesPanel; config.poses holds task-only overrides.

For execution, _execute() packages all tasks or a selected suffix and calls ROS2Bridge.execute_task(). Feedback and results update the queue and chat through callbacks. Most methods below are handlers for existing controls, not a separate scripting API. Follow _connect_signals() when changing a workflow, and keep widget changes on the GUI thread.

MTCMainWindow

Own the operator application’s document and coordinate its panels and bridges. Button and signal handlers edit that document or submit it through ROS2Bridge. closeEvent() disconnects the agent; the application entry point owns ROS cleanup.

Inherits from: QMainWindow.
