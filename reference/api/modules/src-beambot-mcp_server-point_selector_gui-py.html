Image point selector

Show a Tk image window for pixel selection and return the result to the MCP process as JSON. Display configuration is probed by main(), not at import.

src.beambot.mcp_server.point_selector_gui · Source

Perception and mapping · Guide · Symbol index

How it is used

The MCP depth tool starts this script as a separate process when a person must confirm a pixel. main() reads the image and optional initial coordinates, runs the selector, and prints one JSON result to stdout. A Tk installation and usable display are required.

PointSelector.run() manages the window and input callbacks. The displayed image may be scaled down, but returned coordinates always refer to the original image.

Entry point · Source

main()

Returns: None on normal selection/cancel; exits status 1 on a caught GUI/image Exception.

Errors: Argparse errors exit; GUI construction/run Exceptions produce {confirmed:false,error} on stdout before exit(1). A lone –x or –y is ignored.

Side effects: May probe the desktop session and set DISPLAY/XAUTHORITY, then reads the image and opens a GUI; prints a single result line.

PointSelector

Display an image with a movable crosshair and return the selected original-image pixel coordinates together with a confirmation flag.

PointSelector.run()

Show the selector window and wait for confirmation or cancellation. Mouse clicks choose original-image pixel coordinates; keyboard and window callbacks finish the selection.

Method · Source

run(self) -> dict

Returns: {pixel_x,pixel_y,confirmed:true} after confirming a selected point; otherwise {confirmed:false}.

Errors: Tk/display exceptions propagate to main(); confirming without any selected point leaves the window open.

Side effects: Creates an interactive GUI and blocks; selection and result mutate in response to events.

PointSelector.__init__()

Open the image and prepare a resized display image while preserving original-pixel selection coordinates.
