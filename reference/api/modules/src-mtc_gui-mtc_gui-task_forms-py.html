Task editor forms

Edit task dictionaries through a modal form selected by task_type.

mtc_gui.task_forms · Source

Operator GUI · Guide · Symbol index

How it is used

MTCMainWindow calls open_task_form() with a task, its queue index, and the available poses. The helper selects one of the registered editors for 12 task types and returns the accepted task or None. Forms edit a deep copy and do not dispatch commands. Widget construction and editing run on the GUI thread.

Each form supplies build_form() and collect_values() through BaseTaskForm. Most editors preserve unrelated fields. Move To can return _inline_joint_pose metadata for the window to move into the document’s pose overrides; grid editors write a complete config override. These serialization details matter when adding a form or changing the task schema.

Example

# Requires PyQt6 and a configured Qt platform; no ROS or hardware.
# Use an existing QApplication in an application or test harness.
from mtc_gui.task_forms import MoveToForm

form = MoveToForm({"task_type": "moveto", "target": "moveit_home"}, 0, {})
form.mode_combo.setCurrentText("Relative move")
form.direction.setCurrentText("up")
form.distance.setValue(0.05)
assert form.collect_values() == {
    "task_type": "moveto", "direction": "up", "distance": 0.05
}
form.deleteLater()

Parameter

Meaning

step

Task mapping to edit; BaseTaskForm deep-copies it.

step_index

Zero-based queue index used in the title as Step index + 1.

poses

Mapping of named poses to six joint angles in degrees; stored by reference.

parent

Optional parent QWidget.

current_pose

Optional current six-joint pose in degrees used by Read current pose; this is a snapshot, not a polling callback.

Optional callable receiving a six-angle degree list for visual preview only.

Optional zero-argument callback restoring normal viewer state.

Side effects: Creates and executes a modal dialog; only MoveTo receives current-pose/preview/viewer arguments. pause has no dispatch entry.

MoveToForm.collect_values()

Serialize the selected Move To mode and remove fields from inactive modes.

Extension hook · Source

collect_values(self)

Returns: A shallow copy of the working task. Named: target + planning_type=”joint”. Relative: direction + distance (m). Cartesian: planning_type, frame_id, and XYZ metres with RPY degrees appended only if any angle is nonzero. Joint: target + planning_type=”joint” + _inline_joint_pose={name, values}.
