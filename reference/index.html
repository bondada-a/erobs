Task fields and client interfaces

Use Task JSON when writing a task script and ROS action contracts when building a direct ROS client. The orchestrator translates task fields into action goals and supplies values such as resolved poses and the active tool configuration. The two formats are not interchangeable.

MCP tools have their own arguments and effects. A helper that returns task JSON does not execute it; check the tool’s entry before using it.
